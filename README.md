# Online Quiz Platform

A medium-level Flask-based quiz platform with:

- User Login
- Real-time Quiz API
- Dynamic Questions
- Responsive UI
- Flask Backend
- HTML/CSS Frontend

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Open Trivia API

## Features

- Login System
- 5 Real-Time Questions
- Quiz Submission
- Responsive Design

## Run Project

Install Flask:

pip install flask requests

Run:

python app.py
